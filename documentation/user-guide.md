# User Guide

## Citizen reporting flow
1. Open the Report Incident page.
2. Complete the form with reporter details, category, severity, and location.
3. Submit the report for AI-based triage and response routing.

## Tracking flow
1. Use the incident reference ID on the Track Incident page.
2. Review current status, location, and incident progress.

## Admin dashboard
The admin view provides incident volume, priority metrics, and command center summaries.
